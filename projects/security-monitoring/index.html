01 / Context

Overview

A cybersecurity learning lab focused on Windows/Linux events, SIEM fundamentals, and investigation context. It is presented as lab work rather than professional SOC experience.

02 / Intent

Objective

Understand how endpoint and network telemetry becomes useful investigation context and how to distinguish an alert from a verified security incident.

03 / System design

Architecture

Conceptual monitoring flow from endpoints and network telemetry into centralized SIEM review and investigation.

04 / Toolkit

Technologies

  • Wazuh
  • SIEM
  • Windows
  • Linux
  • Wireshark
  • Palo Alto concepts
  • MITRE ATT&CK concepts

05 / Build notes

Implementation

01

Endpoint visibility

Worked with Windows/Linux security-event concepts and Wazuh/SIEM fundamentals for centralized review.

02

Network context

Used Wireshark and firewall coursework concepts to relate endpoint observations to network behaviour and policy context.

06 / Diagnostic reasoning

Troubleshooting

Before treating missing or unexpected telemetry as a security finding, I validate endpoint/source health, timestamps, collection paths, and related network/security context.

07 / Verification

Validation

This portfolio does not claim fabricated detections, customer incidents, or professional SOC outcomes. The focus is investigation methodology and evidence discipline.

08 / Reflection

What I Learned

An alert is a starting point, not a conclusion. Reliable investigation depends on telemetry quality, endpoint context, network evidence, and understanding normal behaviour.
