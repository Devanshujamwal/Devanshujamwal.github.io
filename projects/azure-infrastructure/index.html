01 / Context

Overview

A hands-on Azure learning environment covering compute, virtual networking, access control, storage, security controls, monitoring, and Windows/Linux administration.

02 / Intent

Objective

Build practical familiarity with how Azure compute, networking, permissions, storage, and monitoring work together to support a manageable cloud environment.

03 / System design

Architecture

Conceptual Azure architecture showing the relationship between virtual machines, networking, security controls, identity/access, storage, and monitoring.

05 / Build notes

Implementation

01

Compute & operating systems

Worked with Windows and Linux VM scenarios and connected guest-OS administration with Azure resource management.

02

Networking, identity & monitoring

Practised VNet/NSG concepts, RBAC, storage, Azure Monitor, and Log Analytics fundamentals.

06 / Diagnostic reasoning

Troubleshooting

I separate cloud issues into resource state, network reachability, NSG behaviour, guest-OS state, permissions/RBAC, and monitoring data. That keeps a permission problem from being mistaken for a network problem.

07 / Verification

Validation

This case study represents academic hands-on work. It does not claim ownership of production subscriptions, customer workloads, or undocumented deployment results.

08 / Reflection

What I Learned

A cloud VM is only one part of the service. Networking, identity, permissions, storage, operating-system configuration, and monitoring all affect whether infrastructure is secure and supportable.
